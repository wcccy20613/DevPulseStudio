# DevPulse Studio

DevPulse Studio is an independently developed Android app for discovering Android engineering references, collecting useful projects, and keeping a small personal reading list.

## Highlights

- Kotlin, MVVM, ViewModel, StateFlow and lifecycle-aware UI state
- Retrofit access to the GitHub public repository search API
- Room-backed local favorites for offline access
- Jetpack Navigation and a focused three-tab workflow
- Coil image loading with local placeholders

## Build

Open the project with Android Studio, configure the Android SDK in `local.properties`, then run:

```bash
./gradlew :app:assembleDebug
```
